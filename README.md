# 🌱 Sementes do Tempo

O **Sementes do Tempo** é um portal institucional desenvolvido para uma organização sem fins lucrativos (ONG). 
O projeto foi criado para apoiar uma apresentação escolar, transformando uma visão conceitual em uma plataforma funcional, moderna e totalmente responsiva.

## 🚀 Funcionalidades Principais
* **Interface Institucional Completa:** Páginas dedicadas à história da ONG, projetos em andamento e perguntas frequentes (FAQ).
* **Captação de Recursos e Apoio:** Fluxos estruturados para doações financeiras e cadastro de voluntários.
* **UX/UI Focada em Conversão:** Design limpo com chamadas para ação (CTAs) claras e navegação intuitiva através de um menu fixo.
* **Responsividade Nativa:** Layout adaptável para dispositivos móveis e desktops utilizando CSS puro.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica de múltiplas páginas para melhor acessibilidade.
* **CSS3:** Estilização personalizada, uso de Google Fonts (Inter e Poppins) e layouts baseados em Flexbox.
* **JavaScript:** Manipulação de eventos para interatividade básica no site.

## 📂 Estrutura de Arquivos
* `/index.html`: Página principal com resumo da causa e destaques.
* `/sobre.html`: Detalhes sobre a missão e visão da organização.
* `/doar.html` e `/voluntario.html`: Páginas de engajamento e suporte à comunidade.
* `/assets/css/styles.css`: Centralização da identidade visual do projeto.
